Project 2: Personal Portfolio
This project is a responsive personal portfolio website developed as part of my Web Development Internship at Oasis Infobyte (OIBSIP).

Project Description
The Personal Portfolio is designed to showcase my profile, education, technical skills, projects, and contact information. The website provides a simple and professional way to present my work and web development skills.

Features
Responsive navigation bar
Home section
About section
Skills section
Projects section
Contact section
Profile photo section
LinkedIn link
GitHub link
Email link
Responsive design for mobile and desktop
Interactive features using JavaScript
