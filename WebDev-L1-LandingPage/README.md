Project 1: Landing Page
This project is a responsive landing page developed as part of my Web Development Internship at Oasis Infobyte (OIBSIP).

Project Description
The Landing Page is a simple and attractive website created to practice frontend web development. It includes a navigation bar, hero section, content sections, and footer with a responsive layout.

Features
Responsive navigation bar
Attractive hero section
Multiple content sections
Clean and simple design
Responsive layout for different screen sizes
Footer section
User-friendly interface

CSS3
